# CPE Elective 2 Project

A web application to collect post-activity reports.

### Prerequisites

- Node.js 18.17 or newer
- npm (bundled with Node.js)

### Installation

### Clone this repository
```bash
git clone https://github.com/adobong-sunog/PEPPI-Event-Tracker.git
```

### Install dependencies:
```bash
npm install
```

### Run the development server

```bash
npm run dev
```

Server starts on `http://localhost:3000`

### Default Accounts

- Admin testing account: username `admin`, password `admin123`

## Notes

- Maximum file size is 10 MB per file
- Gallery uploads support PDFs, and images
